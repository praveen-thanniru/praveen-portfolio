# Praveen Thanniru — Personal Portfolio

A recruiter-focused engineering portfolio built with Next.js + Tailwind CSS.

## What this portfolio emphasizes

- Data Engineering → Cloud / Data Platform Engineering career direction
- Quantified engineering impact
- Distributed systems and streaming
- Cloud infrastructure and platform ownership
- Production reliability, observability, CI/CD, Terraform, and Kubernetes

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
npm start
```

## Deploy to Vercel

1. Create a new GitHub repository.
2. Push this project to the repository.
3. Import the repository into Vercel.
4. Vercel will detect Next.js automatically.
5. Add your custom domain later if you want one.
